## Objectives

By the end of this stage, you should be able to install, configure, operate, debug, back up, and restore a CMS without relying on step-by-step instructions.

## Choose a Learning Platform

Do not study several platforms deeply at the same time. Select one traditional CMS first, then add one headless CMS later.

| Platform | Main strength | Best learning use |
|---|---|---|
| WordPress | Large ecosystem and low entry barrier | Rapid website delivery and plugin ecosystem |
| Joomla | Clear extension types and strong access control | Traditional CMS architecture |
| Drupal | Flexible content modeling and enterprise permissions | Complex content and workflow systems |
| Strapi | API-first development | Modern headless CMS |
| Directus | Database-first content management | Data-centric headless architecture |

## Content Management

Learn to configure and use:

- articles or entries;
- content types;
- categories and tags;
- custom fields;
- relationships between content;
- media assets;
- drafts and publication states;
- scheduled publishing;
- revisions and rollback;
- author ownership;
- metadata and SEO fields.

## Presentation and Navigation

Study:

- themes or templates;
- layouts and partials;
- menu trees;
- modules, blocks, or widgets;
- positions or regions;
- template hierarchy;
- responsive behavior;
- asset loading;
- template and layout overrides.

## Users and Access Control

Understand the difference between:

- user identity;
- authentication;
- role;
- group;
- permission;
- ownership;
- access level;
- content-level authorization.

Test permissions with multiple accounts. Never assume that hiding a button in the interface is equivalent to enforcing authorization on the server.

## System Administration

Practice:

- global configuration;
- extension installation and removal;
- URL and SEO configuration;
- cache clearing;
- search configuration;
- email delivery;
- scheduled tasks;
- logs and error reporting;
- environment configuration;
- backup and restore;
- update and rollback procedures.

## Practice Project

Build a complete content website with:

- a home page;
- article list and detail pages;
- categories and tags;
- search;
- contact form;
- media library;
- user login;
- editor dashboard;
- editor and administrator roles;
- SEO metadata;
- cache configuration;
- backup and restore instructions.

Document every configuration decision and its reason.

## Completion Checklist

- [ ] I can install the CMS in a clean environment.
- [ ] I can create a maintainable content model.
- [ ] I can configure menus, layouts, and reusable page regions.
- [ ] I can configure roles and verify permissions with test accounts.
- [ ] I can identify whether a problem belongs to content, configuration, theme, extension, cache, or infrastructure.
- [ ] I can back up and restore both files and database data.
- [ ] I have documented the complete website setup.
