# CMS Overview

Hello, this is the CMS documentation section.

## Purpose

This area contains concepts shared by content management systems before studying a specific platform.

## Planned learning topics

- What a CMS is and when to use one
- Content types, fields, categories, and taxonomies
- Users, roles, permissions, and access control
- Themes, templates, layouts, and overrides
- Plugins, modules, extensions, and packages
- Media management and search
- Security, backups, updates, and maintenance
- Migration planning and content inventory
