# Joomla Overview

Hello, this is the Joomla documentation section.

## Purpose

This area contains Joomla architecture notes, extension development guides, migration documentation, and security checklists.

## Planned learning topics

- Joomla architecture and project structure
- Components, modules, plugins, templates, and languages
- Extension families and package installation
- Template overrides and layouts
- Database structure and content relationships
- Joomla CLI and developer tooling
- Migration from Joomla 3 to Joomla 6
- Third-party extension compatibility
- Security, testing, and deployment

## Suggested structure

```text
docs/joomla/
├── overview.md
├── fundamentals/
├── architecture/
├── extensions/
├── development/
├── migration/
├── security/
└── projects/
```

The folder tree can grow over time without changing the existing pages. New Markdown files will be discovered by MkDocs during the next build while automatic navigation remains enabled.
