## How to Use These Documents

1. Start with the [Joomla 3 Database Overview](./joomla-3/README.md).
2. Read the [Database Structure](./joomla-3/database-structure.md) to understand the main table groups and important columns.
3. Use the [Database ERD](./joomla-3/database-erd.md) to understand relationships between content, categories, menus, modules, users, access control, tags, fields, and extensions.

> The diagrams describe the Joomla 3 core database at a logical level. Third-party and custom extensions may add their own tables and relationships.
