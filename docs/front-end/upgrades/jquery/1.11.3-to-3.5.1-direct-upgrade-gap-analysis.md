# jQuery 1.11.3 → 3.5.1 Direct Upgrade Gap Analysis

> **Purpose:** Provide the master, reviewable gap contract for replacing jQuery `1.11.3` directly with jQuery `3.5.1`.
>
> **Upgrade mode:** **Direct upgrade**. Intermediate releases are not production deployment steps; they are compatibility landmarks whose accumulated behavior is included in the `3.5.1` target.
>
> **Coverage claim:** This document is designed to support **100% coverage of the known/declared jQuery upgrade gap** when every matrix row, discovered runtime asset, declared route/role/state, supported-browser critical flow, compatibility warning, and security finding is classified with evidence.
>
> **Important:** `100% known/declared gap coverage` does **not** mean the whole application is guaranteed bug-free or vulnerability-free. It means there are no silent gaps inside the explicitly discovered and declared jQuery migration scope.

# 1. Executive Summary

## Direct upgrade

```text
jQuery 1.11.3
      │
      │ direct dependency replacement
      ▼
jQuery 3.5.1 FULL BUILD
```

The implementation is one dependency upgrade, but validation must cover the complete accumulated compatibility surface:

```text
1.11.3
   ├── 1.12.x behavior fixes
   ├── browser-support boundary in 3.0
   ├── all jQuery 3.0 breaking changes
   ├── 3.1 ready/error behavior
   ├── 3.2 layout/event/deprecations
   ├── 3.3 deprecation wave
   ├── 3.4 prototype-pollution/event/CSP behavior
   ├── 3.5 htmlPrefilter/XSS behavior
   └── 3.5.1 regression fix
        ↓
      3.5.1
```

## Overall risk

| Area | Risk | Why |
|---|---|---|
| Major version boundary | 🟠 High | Crosses jQuery 3.0 breaking changes |
| Browser support | 🟠 High | jQuery 3.0 no longer supports IE 6/7/8 |
| Legacy plugins/widgets | 🟠 High | May use removed APIs or private internals |
| Ajax | 🟠 High | jqXHR aliases and cross-domain behavior changed |
| Deferred / Promise | 🟠 High | `.then()` adopts Promises/A+ semantics |
| Events | 🟠 High | aliases/internal normalization changed |
| DOM/HTML manipulation | 🟠 High | jQuery 3.5 security-driven HTML parsing change |
| Artifact/build identity | 🟠 High | slim build excludes Ajax/effects |
| Security | 🟢 Improvement | Target contains fixes absent from 1.11.3 |

# 6. Runtime Artifact and Build Identity Gap

Checking only `jQuery.fn.jquery === "3.5.1"` is insufficient.

jQuery releases include different artifacts. The **slim build excludes Ajax and effects modules**, so using it accidentally can break legacy code while reporting the same version.

## Required target contract

```text
Version: 3.5.1
Build: FULL (not slim), unless the project explicitly proves Ajax/effects are not required
Source: local / CDN / bundle
Minified: yes/no
Runtime URL: ...
SHA-256/SRI: ...
Owner: ...
```

## Required checks

- [ ] Runtime reports `3.5.1`.
- [ ] Loaded filename/build is identified.
- [ ] Full vs slim is explicitly classified.
- [ ] Ajax availability is verified if required.
- [ ] Effects availability is verified if required.
- [ ] Local/CDN/bundle source is recorded.
- [ ] Runtime URL is captured.
- [ ] Cryptographic hash or SRI is recorded where practical.
- [ ] No later script replaces the approved jQuery root.

# 7. Legacy Migrate and Compatibility-Shim Gap

## Why this matters

`jQuery 1.11.3` can be paired with **jQuery Migrate 1.x**. jQuery 3.x uses **jQuery Migrate 3.x**. A site may therefore appear compatible on `1.11.3` only because Migrate 1.x or a custom shim restores older pre-1.9 behavior.

## Required discovery

Search for:

```text
jquery-migrate-1.x
jquery-migrate.min.js
jQuery.migrate*
.live(
.die(
custom aliases/polyfills
jQuery.fn extensions that restore removed APIs
manual monkey patches of jQuery internals
```

## Required checks

- [ ] Detect whether Migrate 1.x is loaded in the source runtime.
- [ ] Detect duplicate Migrate copies.
- [ ] Detect custom compatibility shims.
- [ ] Detect monkey-patched jQuery APIs/internals.
- [ ] Classify every shim as REMOVE / REPLACE / KEEP / N/A.
- [ ] Do not load Migrate 1.x with jQuery 3.x.
- [ ] Use Migrate 3.x only with jQuery 3.x.
- [ ] Final release must work without Migrate unless an explicit accepted-risk decision exists.

# 9. Gap B — jQuery 1.x → 3.0

**Risk: 🟠 High. This is the largest compatibility boundary.**

Primary source: https://jquery.com/upgrade-guide/3.0/

## 9.1 Ajax

- `jqXHR.success()` removed → `.done()`.
- `jqXHR.error()` removed → `.fail()`.
- `jqXHR.complete()` removed → `.always()`.
- Cross-domain script execution must be explicitly declared.
- URL hash fragments are preserved by `$.ajax()`.
- `$.get()` / `$.post()` support settings-object signatures.

## 9.2 Attributes and forms

- `.removeAttr()` no longer forces boolean properties to false; use `.prop()` for dynamic state.
- Empty multi-select `.val()` returns `[]`, not `null`.
- SVG documents gain class-operation support; classify plugin assumptions if SVG is used.
- `.toggleClass()` no-argument and boolean-only signatures are deprecated.

## 9.3 Callbacks — previously missing gap

### GAP-3.0-CALLBACK-01 — `Callbacks.lock()` semantics

Locking a callback list prevents **future** list execution; it does not retroactively abort the currently executing list.

Audit:

```text
$.Callbacks(
.lock(
.fire(
.fireWith(
```

## 9.4 Core

Review/classify:

- strict-mode/runtime assumptions;
- asynchronous document-ready timing assumptions;
- removed `.context` and `.selector`;
- removed `.size()` → `.length`;
- removed/changed undocumented internals such as `jQuery.swap`, `jQuery.buildFragment`, `jQuery.domManip`;
- standardized getter values on empty jQuery sets;
- deprecated `jQuery.unique()` → `jQuery.uniqueSort()`;
- deprecated `jQuery.parseJSON()` → `JSON.parse()`;
- non-standard ready signatures.

## 9.5 Data

Dashed keys in the object returned from `.data()` are camelCased.

## 9.6 Deferred / Promise

Review/classify:

- `.then()` callbacks become asynchronous/Promises-A+ compatible;
- thrown exceptions become rejections;
- returned thenables are assimilated;
- rejection-handler return values can become fulfillment values;
- Deferred callback `this` context changes;
- `$.when()` argument/thenable behavior changes;
- `$.when()` progress forwarding is removed.

## 9.7 Dimensions

- `.width()`, `.height()`, `.css("width")`, `.css("height")` may return fractional values.
- `window.outerWidth()/outerHeight()` behavior includes scrollbar dimensions.

## 9.8 Effects

- `.show()/.hide()/.toggle()` respect stylesheet changes differently.
- animations use `requestAnimationFrame`.
- `jQuery.fx.interval` deprecated.
- **Additional easing-function parameters are deprecated**; custom easing functions must not depend on legacy extra arguments.

Audit:

```text
$.easing
.animate(
jQuery.fx.interval
```

## 9.9 Events

- `.load(fn)`, `.unload(fn)`, `.error(fn)` aliases removed.
- `.on("ready", fn)` removed.
- **`event.pageX` / `event.pageY` jQuery normalization removed**; officially supported browsers provide them natively, but legacy/obscure environments or custom event objects must be tested.
- `jQuery.event.props` / `jQuery.event.fixHooks` removed.
- bad delegated selectors throw immediately.
- `.bind()` / `.delegate()` deprecated; `.on()` preferred.

## 9.10 Manipulation

`.wrapAll(function)` invokes the function once for the full collection.

## 9.11 Offset

Invalid inputs to `.offset()` can error; DOM target must be valid for `getBoundingClientRect()`.

## 9.12 Selectors

- `:hidden` / `:visible` semantics changed.
- `$("#")` and `.find("#")` are invalid syntax.
- `$.escapeSelector()` is available for selector-special characters.
- `jQuery.expr[":"]` and `jQuery.expr.filters` are deprecated.

## 9.13 Serialization

`$.param()` no longer converts `%20` to `+` itself.

## 9.14 Traversing

`.andSelf()` removed → `.addBack()`.

# 14. Gap G — jQuery 3.4.1 → 3.5.0

**Risk: 🟠 High. This is the second major compatibility/security gate.**

## `jQuery.htmlPrefilter` change

Self-closing non-void HTML strings are no longer rewritten by the old regex.

Legacy risky examples:

```javascript
$("<div/>")
$("<span/>")
$("<p/>")
```

Search paths through:

```text
.html()
.append()
.prepend()
.before()
.after()
.replaceWith()
$.parseHTML()
$("<html-string>")
```

### Security rule

Do **not** permanently restore the old pre-3.5 htmlPrefilter behavior. The official 3.5 guide warns that restoring it also restores the security-sensitive behavior fixed by 3.5.

If Migrate's `self-closed-tags` compatibility patch is temporarily enabled for diagnosis, it must be removed/disabled for the final secure target unless an explicit security risk is accepted.

## Other 3.5 deprecations

- `jQuery.trim` deprecated.
- Ajax event aliases deprecated; use `.on(...)`.

Official references:

- https://jquery.com/upgrade-guide/3.5/
- https://blog.jquery.com/2020/04/10/jquery-3-5-0-released/

# 15. Gap H — jQuery 3.5.0 → 3.5.1

**Risk: 🟢 Low.**

jQuery 3.5.0 briefly used an internal data object without normal `Object.prototype` behavior, breaking plugins that called `.hasOwnProperty()` directly. jQuery 3.5.1 reverted that regression while retaining the 3.5 security fixes.

Targeting exactly `3.5.1` avoids the 3.5.0 regression.

Official reference:

- https://blog.jquery.com/2020/05/04/jquery-3-5-1-released-fixing-a-regression/

# 17. Static Code Audit

## Rule: do not scan only `*.js`

Legacy CMS/Joomla applications frequently embed JavaScript in PHP templates and HTML/XML assets.

### File types to include

```text
*.js
*.php
*.html
*.htm
*.tmpl
*.xml
```

Priority directories:

```text
templates/
components/
modules/
plugins/
administrator/
media/
```

Exclude generated/vendor directories only when ownership and runtime behavior are separately classified.

```bash
rg -n \
  --glob '*.js' \
  --glob '*.php' \
  --glob '*.html' \
  --glob '*.htm' \
```
